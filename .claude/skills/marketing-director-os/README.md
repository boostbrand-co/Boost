# Marketing Director OS · v2.1

Skill universal de Ana Pau para actuar como Marketing Director / Growth Partner en distintos negocios. Su objetivo es aumentar la calidad de decisiones, impacto y aprendizaje sin multiplicar trabajo innecesario.

## Instalación en Claude

- Subir `Marketing_Director_OS_v2_1_Claude.zip` como skill personalizado, o colocar la carpeta `marketing-director-os/` bajo `.claude/skills/` en Claude Code.
- Mantener `stop-slop-3` como skill editorial **separado**. No sustituye esta metodología de dirección.
- Para Taco Palenque, sumar `taco-palenque-director-os` y sus referencias privadas dentro del proyecto correspondiente. Las referencias de José y otros clientes **no están en este ZIP universal**.

## Uso

Pedir a Claude: `Usa marketing-director-os y stop-slop-3 para esta tarea.`

El skill no debe convertir cada solicitud sencilla en un ejercicio de diagnóstico. Ante trabajos aprobados, ejecutar. Ante nuevas iniciativas complejas, priorizar el cuello de botella y elegir la versión suficiente.

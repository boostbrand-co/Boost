# Taco Palenque · Director OS

Skill de **dirección y criterio** para trabajos de Marketing de las licencias. Vivirá separado de la voz editorial universal y del skill para propuestas a dueños.

## Ruta

`/.claude/skills/taco-palenque-director-os/SKILL.md`

## Uso

1. Para priorización de proyectos, delegación, presupuestos, gestión, análisis de sucursales o decisiones de Marketing, cargar primero `taco-palenque-director-os`.
2. Para inversión a propietarios, añadir `taco-palenque-propuestas-duenos`.
3. Para la redacción del resultado, añadir `stop-slop-3`.
4. Para una presentación, añadir `taco-palenque-presentaciones` y `presentation-design`.

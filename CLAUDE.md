# BOOST Studio OS

This repository contains reusable operating standards for strategy, creative direction, writing, research, presentations, web experience, and client communication.

Before starting work:

1. Read `.claude/skills/README.md`.
2. Identify the relevant reusable skill(s) for the task.
3. Read the applicable `.claude/skills/<skill-name>/SKILL.md` files before drafting or designing.
4. Apply project-specific brand, product, client, and evidence constraints on top of the reusable skill.
5. Do not copy a prior client's branding unless that is the active project.

Use skills for repeatable methodology. Keep client-specific identity, facts, metrics, pricing, and assets inside that client's project files.

Quality standard: work should feel intentional, specific, evidence-led, visually considered, and ready to ship. Do not stop at a clean first pass when the task calls for strategic or creative depth.

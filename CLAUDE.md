# BOOST Studio OS

This repository contains BOOST's reusable operating standards for strategy, research, writing, design, presentations, growth, web experience, and client communication.

## Required startup behavior

Before substantial work:

1. Read `.claude/skills/README.md`.
2. Inspect `.claude/skills/` and identify the relevant skill or skill chain for the task.
3. Read each applicable `.claude/skills/<skill-name>/SKILL.md` before drafting, designing, researching, or coding.
4. Apply project-specific facts, brand rules, product truth, client constraints, and evidence on top of the reusable method.
5. Never copy another client's branding or unsupported facts into a new project.
6. Execute to the acceptance checklist in the active skill(s).

## Skills are reusable methodology

Use skills for repeatable methods and quality standards.

Keep client-specific logos, colors, metrics, pricing, contracts, credentials, and one-off campaign facts inside the client project, not inside global skills.

## When new methodology appears

If a project teaches a reusable lesson:

1. determine whether it belongs inside an existing skill
2. merge before creating a new skill
3. create a new skill only when the workflow is meaningfully distinct
4. follow `studio-os/IMPORT_SKILLS.md` and `studio-os/SKILL_TEMPLATE.md`
5. update both `.claude/skills/README.md` and `studio-os/SKILLS_CATALOG.md`

## Quality standard

Work should feel intentional, specific, evidence-led, visually considered, and ready to ship.

Do not stop at a clean first pass when the task calls for strategic or creative depth.

## Writing standard and Taco Palenque routing

Use `.claude/skills/stop-slop-3/SKILL.md` as the current universal writing standard, not the retained v2 reference. For Taco Palenque strategic work, read `taco-palenque-director-os` first; add `taco-palenque-propuestas-duenos` for owner decisions and `taco-palenque-presentaciones` for slides. Never assume private context is in this public repository.

## Universal Marketing Director / Growth Partner

When work involves marketing direction, growth opportunities, prioritization, delegating or evaluating an execution plan, read `marketing-director-os` before producing substantial new work. It enforces a proportional **minimum-sufficient / move-the-needle** test, without turning simple user tasks into bureaucratic discovery. Use `stop-slop-3` independently for writing. For Taco Palenque, add `taco-palenque-director-os` and owner proposals only when relevant. Never infer that one client's private context applies to another.
